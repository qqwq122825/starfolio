# 来源与整理说明

本仓库是“星策 Starfolio”的合并源码快照，不包含既有仓库的 Git 历史或任何运行数据库。

- `python/`：Investment Watch Python v2 源码与对应测试、样例、说明；核心实现包含 `investment_watch.py`、`paper.py`、`paper_exits.py`
- `web/`：Vue 3 + Element Plus 私有管理版的最终源码快照，源快照提交为 `2e5add8641bf38c11d0da415da95f62dbe92ac35`；原站点部署状态不由本仓库控制
- Web 依赖锁文件、Drizzle 迁移与元数据、Sites 构建适配器和随附第三方许可原样保留，只有与整理和校验相关的轻量调整
