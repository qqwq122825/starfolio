# 两个版本的能力对照

| 能力 | Python v2 本机版 | Web 私有管理版 |
| --- | --- | --- |
| 六页中文管理工作台 | 原静态前端 | Vue 3 + Element Plus 成熟组件库 |
| 自选、人工行情 JSON、证据核验 | 已有 | 已有 |
| 事实阶段 / 相对预期 / 价格观察独立记录 | 已有 | 已有 |
| 按需规则扫描、提醒复核、去重和审计 | 已有 | 已有 |
| 参考持仓 CSV | 本机 SQLite，原子替换 | 云端 D1，原子替换，导入前提示 |
| 日报 | CLI / 页面导出 | 页面下载 |
| 纸面模拟账本与买卖撮合 | 已有；仅模拟 | 未启用；API 返回 501 |
| 分批退出 / 移动止盈 | 可选、显式 test_only，未经收益验证 | 未启用 |
| 身份入口 | 仅本机，无公网账户系统 | 依赖可信 Sites 登录网关及站点访问策略 |
| 存储 | 本机 SQLite | D1，以 Site-scoped 用户 ID 分区 |
| 自动实时行情、新闻、AI API | 未接入 | 未接入 |
| 券商连接、真实交易 | 没有 | 没有 |
| 外部通知、定时作业、24 小时保障 | 未部署 | 未部署 |

## 不把缺失数据当作正常结果

live 模式未配置真实数据源时失败关闭，不回退演示数据。报价过期、在未来、缺少足够可比基线、来源不清或交易日历不足时，相关研究和模拟操作保守阻断。未知新闻证据保持 HOLD，价格上涨不会被用来证明公告事实或超预期。

Web 版本没有简化移植 Python 的接收时间、决策后报价、T+1 和退出状态机约束。因此页面不显示虚构的已执行模拟余额、持仓或收益。

## 数据不会自动同步

两个版本的数据模型和运行时不同，仓库没有复制生产数据，也没有实现跨版本自动迁移。示例 JSON / CSV 用于理解格式，不是对当前市场的判断。不能修改历史样本时间，使其冒充新行情。
