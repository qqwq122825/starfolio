# A股监控与模拟交易数据采购建议

核验日期：2026年10月5日。适用于个人自用、半导体与存储产业链观察池。本文是接入与采购建议，不代表已经购买、获得许可或接通实盘数据。

## 建议顺序

1. **先验证日线、财务和公告逻辑**：Tushare Pro 可作低成本候选。免费日线只能验证部分流程；需要哪些财务、复权、停复牌等接口，应逐项核对权限后再买。
2. **盘中监控与分钟级模拟交易**：优先向米筐询价 RQData 的“历史分钟＋实时 L1/分钟推送”组合。先验收少量观察股的延迟、缺包与盘后对账，再扩容。若该套餐已覆盖财务、公告等需求，不必重复购买另一家相同数据。
3. **真正的订单流研究**：需要逐笔成交、逐笔委托/撤单及订单关联时，再询价 Wind 宏汇 TDFAPI/DataFeed 的沪深 L2 与历史回放。先确认个人能否签约、所需字段和云部署用途获准，再讨论购买。

当前开发和样本回放不要求立即付费。首次购买前，应提供具体套餐、总价、期限、续费方式、许可范围与退款限制供确认。

## 三个候选的能力和边界

### Tushare Pro 基础研究数据

- 官方支持 Python SDK 与 HTTP；通用 `pro_bar` 是 SDK 组合接口，文档明确不能直接用 HTTP 调它。`daily` 是未复权日线，通常交易日15—16时入库，停牌无记录，不能当实时行情。[调用与复权](https://tushare.pro/document/1?doc_id=109) · [日线字段](https://tushare.pro/document/2?doc_id=27)
- 财务指标 `fina_indicator` 需至少2000积分；按季度全市场的 VIP 接口需5000积分。利润表提供公告日、实际公告日、报告期和修订类型，但这些日期字段不能自动保证盘中时点可得性。[财务指标](https://tushare.pro/document/2?doc_id=79) · [利润表](https://tushare.pro/document/2?doc_id=33)
- 官网个人价：2000积分档 **¥200/年**，5000积分档 **¥500/年**；历史分钟 **¥2,000/年**、实时分钟 **¥1,000/月**、公告 **¥1,000/年**均属独立权限。基础积分不含这些独立权限。该页说明机构价为个人价10倍、购买后不支持退款；最终以购买时账号及订单为准。[官方价格与权限](https://tushare.pro/document/2?doc_id=290)
- 云端：官网说明可本地落库，但这不等于授予再分发权或任意云部署权。官方变更记录限制同账号多个 IP 同时提取。个人独享服务器、部署地区、IP/并发、缓存和对外展示应取得书面确认；不在前端放 Token。[产品说明](https://tushare.pro/) · [访问机制变更](https://tushare.pro/document/1?doc_id=9) · [服务协议](https://tushare.pro/document/1?doc_id=405)
- **本次未核验到完整 L2 订单事件流权限**。资金流向、筹码和大单统计都是各自口径的派生数据，不能据此重建真实逐笔委托，也不能识别“主力账户”。

### 米筐 RQData 盘中与历史数据候选

- 官方列出 A 股历史日/分钟/tick、实时 tick/分钟、财务等数据；有独立 Python 客户端、HTTP，实时另有 `LiveMarketDataClient`/WebSocket。SDK 支持 Linux，需有效商业授权。[产品范围](https://www.ricequant.com/doc/rqdata/python/) · [安装与许可](https://www.ricequant.com/doc/rqsdk/manual-rqsdk) · [HTTP](https://www.ricequant.com/doc/rqdata/http/data-process)
- 文档的实时推送是 **L1 五档快照 tick 和分钟聚合**，不是逐笔成交/委托全事件流；列明主板、创业板、科创板，北交所覆盖需另询。实时分钟可能因晚到 tick 与盘后清洗版不同，系统应保存两种版本。[行情与实时推送](https://www.ricequant.com/doc/rqdata/python/generic-api)
- `get_pit_financials_ex` 能按查询日期回溯季度财务并保留修订记录，有助于减少未来数据泄漏；调用时必须显式传历史日期。完整财报、快报和预告属于不同数据对象。[PIT 财务文档](https://www.ricequant.com/doc/rqdata/python/stock-mod)
- **价格待询价**：本次未核到适用于本项目、可直接购买的公开套餐总价。须确认历史和实时分别包含哪些权限、流量、并发、订阅数、更新时限与 SLA；技术上支持 Linux/服务端，不等于合同已允许任意云区域、多实例、第三方托管或公开展示。

### Wind 宏汇 TDFAPI 授权 L2 候选

- Wind 官网称宏汇为交易所授权行情转发信息商；英文页明确列出实时 L2 DataFeed 与 TDFAPI 的 Python 支持，中文页列历史逐笔成交、逐笔委托、委托队列及盘后回放。[中文产品页](https://www.wind.com.cn/mobile/WDS/marketdata/zh.html) · [英文产品页](https://www.wind.com.cn/mobile/WDS/marketdata/en.html)
- **价格、个人客户准入、Linux/云部署、实时逐笔字段覆盖均待书面报价与样本验收**。产品介绍不能证明某个套餐含沪深全部逐笔委托/撤单、全深度订单簿或指定年限历史；需索要当前数据字典、许可及接入规格。普通 Wind 终端或零售 L2 看盘订阅不能视为 TDFAPI 授权。
- 上证信息将 L2 的展示和非展示许可分列。服务器因子计算、模拟撮合、存储及向网页/其他人展示，应逐项确认用途与所需许可，沪深分别确认；不自行把“个人自用”理解为豁免。[交易所 L2 产品及许可入口](https://www.sseinfo.com/services/assortment/level2/)

## 上线前必须通过的验收

以下为本系统工程要求，不是供应商保证：

- **新鲜度**：保留来源、交易所事件时间、服务端接收时间、交易日、数据模式、版本和质量状态；页面明确显示历史/延迟/实时/演示。按交易时段与标的活跃度检查心跳、积压、断流和最新时间。过期或缺失数据应暂停依赖它的模拟成交，不用旧收盘价冒充当前可成交价。
- **交易日历与状态**：使用交易所/供应商交易日历，处理节假日、午休、集合竞价、临时停牌、复牌、退市和板块规则；不得仅按工作日推定开市。日线缺行不能直接等同停牌。
- **单位与复权**：统一元/股与成交量单位。例如 Tushare 日线量为手、金额为千元，实时分钟为股/元。模拟成交使用未复权价格；信号可用单独复权序列。保留除权除息日、股权登记日、现金分红/送转及复权因子版本，避免重复计算收益。[日线单位](https://tushare.pro/document/2?doc_id=27) · [分钟单位](https://tushare.pro/document/2?doc_id=374)
- **涨跌停与可成交性**：以当日证券状态及上下限价格判断，不对所有股票写死同一比例。T+1、最小申报量、费用与滑点另行建模；触及涨停或K线经过价格不代表订单必然成交，L1 数据不能给出真实排队位置。
- **时点财务与公告**：区分报告期、公告发布时间、首次可获得时间、抓取时间和修订版本；保留公告原链接与内容哈希。回测只使用当时已知版本；仅有公告日期时不得假装拥有盘中精确发布时间，应采用保守可用时间并显式标记。
- **L2 完整性**：分别确认沪/深逐笔成交、委托、撤单、序号/通道、订单关联、竞价与盘后数据、快照档位、乱序/重发/补历史规则。断序或补包未完成时，暂停订单流因子和依赖它的模拟撮合。
- **观察池版本**：半导体/存储标签需有来源、证据日期和生效区间；主营收入暴露与概念标签分开，保存历史成分和退市股，避免用今天的行业名单回测过去。

## 询价时一次问清

提供计划中的观察股数量、频率、历史年限、服务器区域、实例数和个人自用方式，要求供应商逐项回复：含税总价与期限、自动续费及退款；接口和数据字典；交易所来源及有效授权；展示/非展示与衍生数据权限；Python/Linux/云主机及 IP 限制；历史保存、缓存、备份和终止后的删除要求；订阅/流量限制；延迟目标、故障补数与支持渠道。

文档可访问和 SDK 可安装均不证明账号已经获得该数据权限。未取得许可和凭据前，应用应维持明确标注的演示/历史回放状态。
