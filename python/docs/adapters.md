# 只读数据适配契约

## 已验证与未验证

公开交易所网页可以读取不代表获得程序化行情服务和再分发许可。本次未核验出可以启用的稳定、无凭据、字段口径明确的公共实时行情源，因此没有开启实时适配器。

候选网页如 https://www.szse.cn/English/siteMarketData/siteMarketDatas/lookup/index.html?code=300003 和上交所授权行情服务 https://www.sse.com.cn/transparency/services/index.shtml 只作为后续接入背景，不是已支持的 API。端点、时延、字段、单位、调用频率和许可须另行验证。

## 行情 import-market / POST /api/import/market

JSON 数组，每项：

```json
{
  "symbol": "600000",
  "observed_at": "2026-09-28T10:00:00+08:00",
  "source": "数据源名称（示例）",
  "source_url": "https://www.sse.com.cn/",
  "price": 10.0,
  "change_pct": -1.1,
  "volume": 24000000,
  "turnover": 240000000,
  "large_order_net": 28000000,
  "flow_definition": "请填写供应商逐笔分类标准及买卖方向统计方法",
  "baseline": [100000000,102000000,98000000,105000000,95000000,100000000,102000000,98000000,105000000,95000000,100000000,102000000,98000000,105000000,95000000,100000000,102000000,98000000,105000000,95000000],
  "baseline_basis": "前20个交易日相同累计时段；人民币元；说明除权等处理",
  "series": []
}
```

- observed_at 是行情源观察时间，必须带时区；程序另记 fetched_at，不得替代
- 价格是人民币元/股、成交量是股、成交额/净额是人民币元、涨跌幅是百分比数值（-1.1 表示 -1.1%）
- large_order_net 未获取时填 null，不能填虚构的 0，不得从价格涨跌或 L1 五档推算真正资金流
- 大单分类是供应商统计，无法识别交易者身份。基线必须可比，禁止日终成交额与盘中累计直接比较
- 基线只用于异常筛选，不可作为模拟撮合价。执行价须独立取得原始未复权报价；复权历史仅用于明确口径的统计
- 至少20点才能算异常。原型尚未包含自动历史拉取、单位映射、基线交易日期溯源、跨源一致性核验
- 默认 importer 是数据来源声明，不是“已独立验证”或“实时接口”

## 适配器调用契约

后续授权数据源可以实现零参数 provider() -> list[dict]，传入 run_monitor(conn,'imported',provider=provider)。默认最多3次、指数退避0.3/0.6秒（正式环境应按授权频率配置）。每项都经过相同校验。不要在代码库、日志、URL 或导出 ZIP 内写入密钥。尚未定义真实 live API 配置。

没有数据时抛异常或返回空列表；禁止静默返回 demo；重试不能更新 observed_at；延迟行情要明确显示源时延；公告/财经原文要保留源 URL、发布时间与抓取时间。

## 未来只读持仓 API

只预留接口概念：read_positions() -> {as_of, source, positions:[{symbol, exchange, shares, available_shares, average_cost}]}。

允许的范围是查询，不包含下单、改单、撤单、转账、融资、API 密钥创建或持久权限配置。尚无券商，尚无认证实现。后续接入前须确认具体机构、只读权限与敏感数据范围。
